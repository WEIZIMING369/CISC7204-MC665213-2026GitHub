## Learning path

### 01 — Importing data
Load course datasets and inspect their structure as the starting point for analysis.

### 02 — Data wrangling
Clean and transform source data into forms that can be explored and modelled.

### 03 — Exploratory data analysis
Use summaries and visual exploration to understand variables and relationships.

### 04 — Model development
Build analytical models from prepared data.

### 05 — Evaluation and refinement
Assess model performance and consider ways to improve the analysis.

### 06 — Applied projects
Apply the workflow to insurance cost and house pricing questions through a practice project and a final project.

## Included datasets

The source archive contains the supporting files used by the notebooks, including laptop pricing, automobile, housing and medical insurance data. Some files are provided in both a project folder and at the archive root to support the original notebook paths.

## Open and run

1. Download and extract [source.zip](source.zip).
2. Open a notebook for the module you want to review.
3. Keep the extracted `data` folder and CSV files in their supplied locations so relative paths continue to work.
4. Install the Python packages imported by that notebook before running it.

Notebook outputs and screenshots were omitted from the public archive. The notebooks and supporting data remain available as editable source files.
